## The 7-Asset Machine (Wojo-Modeled)

Wojo's model that this funnel mirrors:
1. **Low-ticket front-end** — self-liquidating book/playbook ($7)
2. **Physical book** — authority anchor (The Financial Architect's Playbook)
3. **VSL / Webinar** — evergreen pre-call asset (record once, runs forever)
4. **High-ticket back-end** — the install (your $2,997–$15,000 tiers)
5. **Paid traffic** — Meta + Google (start $50–$100/day; scale to $1K+/day)
6. **Delivery team** — you now, VA at $5K/mo client volume, sales closer at saturation
7. **Community layer** — Architect's Circle for MRR

### Phase 1 — Days 1–30 (Foundation)
- [ ] Lock all offer names, prices, and deliverables (done — use this doc)

### Phase 2 — Days 31–60 (The Funnel)

- [ ] Email/SMS sequences for book buyers (7-email welcome sequence)

### Phase 3 — Days 61–90 (VSL)
- [ ] Record 8–10 min VSL using existing script (from marketing materials)
- [ ] Host on Vimeo Pro or YouTube (unlisted)
- [ ] Embed on landing page above CTA
- [ ] Don't perfect it — get it done; you can re-record at $10K/mo

### Phase 4 — Days 91–150 (Traffic)
- [ ] Start Meta ads: $50–$100/day to book funnel
- [ ] Target: realtors, LOs, 1099 professionals, age 28–55
- [ ] Initial creative: 2 video ads using Reel scripts + 3 image ads
- [ ] Hire freelance media buyer at $1,500–$3,000/mo when funnel is proven

### Phase 5 — Days 150–270 (Delivery & Team)
- [ ] Hire ops associate ($2,500–$4,000/mo) when hitting $15K/mo in audits

### Phase 6 — Months 9–12 (Community)
- [ ] Launch Architect's Circle on Skool or Circle.so ($39–$99/mo platform cost)
- [ ] Price at $197/mo, include all Blueprint Mini-Course graduates free for 90 days

## Biggest Mistake to Avoid

Building the community, the VSL, and the paid traffic simultaneously before the funnel is converting organically. 

**Right sequence:**
1. Prove the offer works organically (DMs, warm network, JV partners) → first $10K
2. Build the funnel (book + ladder) → self-fund
3. Test paid traffic with $1,000 budget → prove cost-per-lead
4. Scale traffic when CPL < $5 and backend is converting at 60%+
5. Add the community and team only when volume demands it

Revenue buys the next phase. Don't borrow or overinvest before organic is proven.

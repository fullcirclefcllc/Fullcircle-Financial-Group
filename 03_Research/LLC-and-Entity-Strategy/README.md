# LLC & Entity Strategy — Research

## Entity Types Overview

| Entity | Liability Protection | Tax Treatment | Best For |
|---|---|---|---|
| Sole Proprietorship | None | Pass-through | Starting out only |
| Single-Member LLC | Yes | Pass-through / Disregarded | Solo operators |
| Multi-Member LLC | Yes | Pass-through (partnership) | Partners |
| S-Corp Election (LLC) | Yes | Pass-through + salary split | High-income earners |
| C-Corp | Yes | Double taxation (or retained earnings) | Scaling / investors |
| Holding LLC | Yes | Pass-through | Asset separation |

## Holding Company Structure

```
Holding LLC (owns assets, holds equity)
├── Operating LLC A (active business)
├── Operating LLC B (second venture / real estate)
└── Investment Account / Policy
```

**Why:** Lawsuit against the operating LLC cannot reach assets held in the holding company.

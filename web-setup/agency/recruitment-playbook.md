# Agency Recruitment Playbook — Recruit Agencies, Not Just Agents

**Target:** Agency principals, team leaders, IMO downline builders — minimum 3 licensed agents or intent to build a team.

---

## Recruitment Funnel

```
Awareness → Application → Qualification Call → Agency Agreement → GHL Sub-Account Provisioned → Admin Training → First Production (30 days)
```

Pipeline: [`../ghl/pipelines/agency-recruitment-pipeline.md`](../ghl/pipelines/agency-recruitment-pipeline.md)

## 90-Day Agency Onboarding

### Days 1–7: Provision & Configure
- [ ] GHL sub-account created from snapshot
- [ ] Custom menu configured per tab-architecture.md
- [ ] Agency branding (logo, colors, domain)
- [ ] Admin user + agent seats provisioned
- [ ] Carrier appointment list imported to custom fields

### Days 8–30: Train & Certify
- [ ] Agency Admin completes Admin Certification (Membership)
- [ ] All agents complete Term Foundations
- [ ] At least 1 agent completes IUL Mastery (agency lead producer)
- [ ] Compliance workflow walkthrough
- [ ] First 10 leads loaded into CRM

### Days 31–60: Produce
- [ ] First 5 applications submitted across product pipelines
- [ ] KPI dashboard reviewed weekly
- [ ] Recruitment pipeline active (if Growth+ tier)
- [ ] Peer network intro (community channel)

### Days 61–90: Scale
- [ ] 90-day persistency tracked
- [ ] Product mix review (term vs whole vs IUL)
- [ ] Cross-sell coaching for top producers
- [ ] Renewal / upgrade conversation for next tier

## Objection Handlers

| Objection | Response |
|-----------|----------|
| "We already have a CRM" | "Does it have IUL-specific pipelines, licensing alerts, and 13-month persistency tracking out of the box? Agency OS is insurance-native, not adapted from generic CRM." |
| "Too expensive" | "Spreadsheet CRM costs you in lapsed policies and compliance gaps. One saved chargeback or one retained agent pays for the year." |
| "My agents won't adopt" | "Training is built in — certification gates before complex products. Agents who complete IUL Mastery close 2x IUL vs uncertified." |
| "We're too small" | "Starter tier is built for 3-agent shops. You get the same architecture Symmetry-scale orgs use — you grow into it." |

## Days 4–7 — Discovery & Close

| Step | SLA |
|------|-----|
| Respond to inbound | <24 hours |
| Book discovery call | Same day if possible |
| Run discovery (45 min) | Use intake questionnaire as guide |
| Send proposal same day | SalesCloser — 24hr max |
| Collect payment | Stripe link in follow-up |

**Discovery call structure:**
1. Confirm intake answers (10 min)
2. 4-Pillar scorecard conversation (15 min)
3. Leakage estimate — "$18K–$42K range based on what you've shared" (10 min)
4. Present PPA deliverable + backend path (5 min)
5. Close or schedule follow-up (5 min)

## Days 8–14 — Fulfillment Cycle

### Per Paid Audit

| Day | Action | Time |
|-----|--------|------|
| 0 | Client pays → Calendly booked → intake questionnaire sent | 15 min |
| 1–3 | Diagnostic call (45 min) | 45 min |
| 3–4 | Run Claude Prompts 0–4 → blueprint draft | 60–90 min |
| 4–5 | Review, polish, format in Google Docs → PDF | 30–45 min |
| 5–7 | Walkthrough call (60 min) + upsell | 60 min |
| 7+ | 30 days Voxer/email support | Ongoing |

**Capacity:** 3–5 audits/week solo. 8–12/month with FulfillmentLead agent.

### Fulfillment Checklist (Per Client)

- [ ] Intake questionnaire complete before diagnostic
- [ ] Diagnostic call recorded / notes captured
- [ ] Prompts 0–4 run with real numbers
- [ ] Blueprint reviewed by Breyon before walkthrough
- [ ] Walkthrough scheduled within 5 business days of blueprint complete
- [ ] Upsell offer presented (Foundation/Blueprint/DWY)
- [ ] 90-day checklist emailed post-walkthrough
- [ ] Client folder updated in `02_Clients/[Name]/`

## Troubleshooting

| Issue | Fix |
|-------|-----|
| No discovery calls | Increase outbound 2x, run JV emails |
| Low close rate | Review discovery script, add urgency hook |
| Blueprint taking too long | Use FulfillmentLead agent, batch Prompts 1–4 |
| No backend upsell | Strengthen walkthrough script section X in fulfillment-playbook |
| Client ghosted after pay | SMS + email within 24hr to book diagnostic |

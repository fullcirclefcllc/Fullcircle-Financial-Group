# Agent Recruitment Pipeline

**Pipeline Name:** Agent Recruitment  
**Purpose:** Recruit individual licensed agents into an agency using Agency OS

---

## Stages

| # | Stage | Definition | Max Days | Auto-Action |
|---|-------|------------|----------|-------------|
| 1 | **Prospect** | Potential agent identified | 3 | Tag `recruit:agent-prospect` |
| 2 | **Contacted** | Initial outreach | 2 | Archetype assessment link |
| 3 | **Interest Confirmed** | Wants to learn more | 3 | Send recruiting deck + comp overview |
| 4 | **Interview Scheduled** | Recruiting call booked | 5 | Calendar + pre-interview form |
| 5 | **Interview Complete** | Fit assessed | 3 | Archetype assigned |
| 6 | **Offer Extended** | Comp package presented | 5 | Follow-up sequence |
| 7 | **Contracting** | License verification, contracting paperwork | 14 | Document collection workflow |
| 8 | **Appointed** | Carrier appointments active | 21 | Training enrollment |
| 9 | **Certified & Active** | Term cert complete, first lead assigned | 30 | Production tracking begins |
| 10 | **Lost** | Did not join | — | Quarterly nurture |

---

## Archetype Assignment (Stage 5)

| Archetype | Onboarding Track | First Product |
|-----------|------------------|---------------|
| Digital Nomad | Remote tech setup + async Term track | Term |
| Community Pillar | Local marketing kit + event training | Term + Whole |
| Cross-Sell Professional | Annuity-to-life bridge training | Whole + IUL |
| Agency Builder | Admin track + recruitment tab | All + recruit |

---

## Contracting Checklist (Stage 7)

- [ ] NPN verified (NIPR)
- [ ] State license active
- [ ] E&O policy on file
- [ ] Background check (if required)
- [ ] W-9 / direct deposit
- [ ] Carrier contracting forms submitted
- [ ] GHL user account created
- [ ] Archetype-specific onboarding scheduled
